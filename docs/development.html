Project structure

  • src/ai/keqing/ — AI chat, completion, memory, persona, and Discord handler
  • src/social/ — link-domain registry, rewriting, cards, and message/reaction handlers
  • src/music/ — player lifecycle, player events, and lyrics
  • src/tts/ — ElevenLabs/Google synthesis and the TTS extractor
  • src/commands/ — admin, integrations, music, and utility slash commands
  • src/db/ — Drizzle schema and PostgreSQL storage
  • src/events/, src/loaders/, src/structures/ — gateway wiring and discovery
  • scripts/ — deploy, clear, and smoke entry points
  • test/ — tests mirrored by domain

Tests and coverage

Run the suite or the coverage gate from the repository root:

bun test
bun run test:coverage

bunfig.toml enforces 100% line and function coverage for the unit-testable core: configuration, database storage, AI completion/memory/persona, NovelPia, lyrics, social link logic, TTS providers, embeds, and the module loader.

Discord/player/social-rendering adapters, bootstrap, and external clients are explicitly excluded in bunfig.toml.

Continuous integration

CI runs on pushes and pull requests to master:

  • bun install --frozen-lockfile
  • bun run check
  • bun run test:coverage against a PostgreSQL 16 service
  • bun run build

Operational scripts

  • bun run deploy:commands — deploy slash commands
  • bun run deploy:clear-commands — clear deployed commands
  • bun run smoke — verify schema, command registration, AI config, and TTS state
