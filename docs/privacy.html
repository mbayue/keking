Privacy.

What Keking reads, what it stores, and what happens to your data.

1. Data We Read

When you invite Keking, the bot reads server IDs, channel IDs, voice states, and the messages it needs to answer commands and spot links.

2. How We Use It

We use this data to make the bot work: playing the song you asked for, reading the text you sent to speech, and unfurling the link you posted.

3. Data We Store

If you enable the database, Keking stores basic server info: server ID, command settings, and link-preview preferences.

Keking stores no message text, no user profiles, and no chat history.

4. Message Content

Keking scans messages in real time to fix bad social media links. We do not save this text. We do not use it to build profiles.

5. AI Training

We do not train AI models on your messages or data.

6. Data Sharing

We sell nothing. We share nothing. Keking only sends queries to external APIs (like Genius or YouTube) when you ask it to find lyrics or songs.

7. Deletion

Kick the bot, and it stops reading data. If you run the database, deleting your server's record removes what was stored.

8. Contact

Create an issue on GitHub if you need help with your data.
