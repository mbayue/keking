Privacy.

What Keking reads, what it stores, and what happens to your data.

1. Data We Read

When you invite Keking, the bot reads server IDs, channel IDs, voice states, and the messages it needs to answer commands, spot links, and handle AI chat mentions or replies.

2. How We Use It

We use this data to make the bot work: playing the song you asked for, reading the text you sent to speech, and unfurling the link you posted. If AI chat is enabled, messages that mention the bot or reply to it are sent to the configured AI provider to generate a reply. If Keking is connected to a voice channel, the reply is also sent to the configured TTS provider (Google Translate or ElevenLabs, depending on configuration) to be spoken.

3. Data We Store

If you enable the database, Keking stores basic server info: server ID, command settings, and link-preview preferences.

If AI chat is enabled, Keking stores the last 10 messages (5 exchanges) per user per server in PostgreSQL so it can continue conversations. AI memory older than 30 days is deleted automatically. Use /forget to delete your stored AI memory; deleting your server’s record also removes it.

Keking does not store social-preview message text or user profiles.

4. Message Content

Keking scans messages in real time to fix bad social media links. We do not save this text. We do not use it to build profiles. When you trigger AI chat, the message and the recent conversation context are sent to the configured AI provider; the last 10 messages are stored in PostgreSQL for continuity. If you reply to a message, that referenced message is included as quoted context for that request only and is not stored as AI memory. If you explicitly ask for a channel recap (for example, “summarize this conversation”), up to 50 recent messages are sent to the AI provider for that request only and are not stored as AI memory.

5. AI Training

We do not train AI models on your messages or data. The configured AI provider's own privacy and retention policies apply to requests sent to it.

6. Data Sharing

We sell nothing. Keking sends queries to external APIs only for the feature you use: Genius or YouTube for lyrics and music, mirror and metadata services for link previews, the configured AI provider for AI chat, and the configured TTS provider (Google Translate or ElevenLabs) for spoken replies.

7. Deletion

Use /forget to delete your stored AI memory. Server admins can use /forget all to delete all AI memory in the server. Kick the bot to stop it reading new data. If you run the database, deleting your server's record also removes its stored AI memory and settings.

8. Contact

Create an issue on GitHub if you need help with your data.
